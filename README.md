# 📋 Gerenciador de Usuários - CLI PHP

Este é um projeto simples de linha de comando em PHP que permite gerenciar usuários através de um menu interativo.

## 🚀 Funcionalidades

- ✅ Criar um novo usuário
- ✅ Excluir um usuário existente
- ✅ Listar todos os usuários
- ✅ Editar nome e email de um usuário
- ✅ Buscar informações de um único usuário
- ✅ Sair do programa

## 🛠️ Requisitos

- PHP 7.0 ou superior
- Terminal com suporte a entrada/saída

## 🧪 Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/VitorGirottto/usuarios.git
cd usuarios
php usuarios.php
```
